## Features

- **WHATWG URL Standard**: Conforms to modern WHATWG URL standards via pure-Python `pywhatwgurl` with optional high-speed C++ backends (`can-ada`, `ada-url`).
- **Protocols Supported**: HTTP, HTTPS, SOCKS4, and SOCKS5 (with `socks4a` and `socks5h` remote DNS schemes).
- **Network Compatibility**: Full support for IPv4, IPv6 (RFC bracketed), UTF-8 Unicode credentials, and IDN / Punycode domain names.
- **Flexible Ingestion**: Parse from URLs, strings (with format auto-detection), dictionaries, JSON, and text files (sync & async generators).
- **Immutable & Safe**: Frozen `@attrs.frozen` instances with `with_*` evolution methods and strict port/protocol validation.
- **Client Integrations**: Built-in `prepare_for()` for `requests`, `httpx`, `aiohttp`, `playwright`, `curl_cffi`, and more.

## Installation

```bash
# Using uv (recommended)
uv add proxy-string

# Using pip
pip install proxy-string
```

For maximum URL parsing throughput, optional C++ WHATWG URL backends can be installed:

```bash
uv add "proxy-string[can_ada]"  # or "proxy-string[ada_url]"
```

## Quick Start

```python
from proxy_string import ProxyServer, ProxyServerProtocol

# 1. Parse from URL (supports Unicode credentials and remote DNS)
proxy = ProxyServer.from_url("socks5h://юзер:пароль@proxy.example.com:1080")
print(proxy.protocol)  # ProxyServerProtocol.SOCKS5
print(proxy.remote_dns)  # True

# 2. Parse from text string (format auto-detected)
auto = ProxyServer.from_string("192.168.1.1:8080:alice:secret")
print(auto.host)  # '192.168.1.1'
print(auto.port)  # 8080

# 3. Create modified copies (objects are immutable)
updated = auto.with_port(9090).with_creds("bob", "new_pass")

# 4. Export configuration for third-party HTTP clients
requests_config = updated.prepare_for("requests")
print(requests_config)
# {'http': 'http://bob:new_pass@192.168.1.1:9090', 'https': 'http://bob:new_pass@192.168.1.1:9090'}
```

## Development

```bash
# Clone the repository
git clone https://github.com/sergey-scat/proxy-string.git
cd proxy-string

# Install all dependencies including docs and dev groups
uv sync --all-extras --dev --group docs

# Run tests with coverage
uv run pytest

# Check code formatting and linting
uv run ruff check .
uv run ruff format --check .

# Static type check
uv run ty check src/proxy_string

# Build documentation locally
uv run mkdocs serve
```
